# Information Gain Analysis

**Methodology:** Each answer was evaluated for how much new, usable signal it provides for building a behavioral model. Flags fall into these categories:

- **EMPTY** — Answer is so short or generic it could be anyone
- **INCOMPLETE** — Question asked for multiple things, only some were answered
- **REDUNDANT** — Answer repeats information already captured in another answer
- **DEFLECTED** — The actual question was dodged or reframed
- **MISSING WHY** — A choice was given but no reasoning, which the question explicitly asked for
- **CONTRADICTS** — Answer conflicts with another answer, creating ambiguity

Questions not listed here had acceptable-to-excellent information gain.
